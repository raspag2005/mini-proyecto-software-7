## Introducción

La presente asignación tiene como objetivo aplicar los conocimientos adquiridos en programación web utilizando **PHP** y **Bootstrap** para resolver una serie de problemas de lógica, matemáticas y estadística.

A través del desarrollo de diferentes módulos, se implementan:

* Estructuras de control
* Ciclos iterativos
* Arreglos
* Formularios web
* Procesamiento de datos ingresados por el usuario

Cada ejercicio plantea una situación específica que requiere el análisis de información, la realización de cálculos y la presentación de resultados de manera clara y organizada mediante una interfaz web.

De esta forma, se fortalecen las habilidades de programación, el razonamiento lógico y el diseño de aplicaciones dinámicas orientadas a la solución de problemas.

## Funcionalidades Implementadas

* Resolución de problemas matemáticos.

* Manipulación de arreglos.
* Uso de formularios para captura de datos.
* Aplicación de estructuras condicionales y repetitivas.
* Generación dinámica de resultados mediante PHP.
